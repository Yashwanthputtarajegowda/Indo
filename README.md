# Indo

A modern social media app built with Flutter and Firebase.

## Product
- Authentication
- Home feed
- Stories
- Create photo/video/text posts
- Profiles
- User search
- Follow/unfollow
- Likes and comments
- Real-time messaging
- Notifications
- Privacy, block and report

## Stack
- Flutter / Dart
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Firebase Cloud Messaging
- Cloud Functions (planned)

## Status
Foundation build started. Firebase credentials are intentionally not committed to the repository.
