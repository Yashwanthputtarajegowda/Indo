# Indo Android APK build

The repository is prepared for an Android wrapper with Capacitor.

1. Install Capacitor packages in a local build environment.
2. Add the Android platform.
3. Build the web app and sync the Capacitor Android project.
4. Open the Android project in Android Studio.
5. Configure the production Indo API base URL and signing keystore.
6. Build a release APK/AAB and test it on a real Android device.

This repository currently contains the Capacitor app configuration only; an APK has not been generated yet.
